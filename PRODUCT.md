# Small Web

## Product
A web app that acts as a browser for a seeded “small web” of one-page HTML sites stored in MongoDB.

## Users
Interview candidates / reviewers browsing as a named person (no accounts). Authors publish HTML pages at addresses like `tidepool.zz`.

## Jobs to be done
1. Type or follow an address and read the page
2. Back / forward with restore of the page that was left
3. Scroll and jump personal history
4. Search page prose across the web
5. Publish a new address + HTML page

## Non-goals
Auth, tabs, bookmarks, extensions, downloads, real network, Electron.

## Mode
Operate — tool chrome around a reading viewport. Clarity and correct navigation outrank decoration.
