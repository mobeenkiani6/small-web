# Small Web — Design system

## World
Midnight transit wayfinding. The browser chrome is enamel night; pages read on a porcelain stage. Addresses behave like stations on a route.

## Tokens
- Shell: `#070b14` / `#101826`
- Stage: `#f7f5f0`
- Active line: `#3d7eff`
- Alert / miss: `#ff3b4a`
- Type: Public Sans + IBM Plex Mono (addresses)

## Signature
Session **route strip** under the toolbar — connected station dots for back/forward jumps.
